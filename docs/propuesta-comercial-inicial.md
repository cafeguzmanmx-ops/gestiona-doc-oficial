# Propuesta comercial inicial — Gestiona Doc

## Producto

Gestiona Doc es una plataforma SaaS para el control de correspondencia oficial de gobiernos municipales mexicanos.

## Problema

Muchos municipios controlan oficios con hojas de cálculo, carpetas físicas, correos aislados y mensajes de WhatsApp. Esto genera pérdida de trazabilidad, vencimientos, duplicidad de tareas y dificultad para reportar avances a Presidencia Municipal, Secretaría del Ayuntamiento, Contraloría y áreas operativas.

## Solución

Gestiona Doc centraliza el ciclo de vida del oficio:

- recepción,
- folio interno,
- turnado,
- seguimiento,
- alertas,
- cierre,
- reportes,
- auditoría.

## Planes sugeridos

| Plan | Perfil | Precio anual sugerido |
|---|---|---:|
| Piloto municipal | Validación inicial | $12,000 a $18,000 MXN |
| Municipal básico | Municipio pequeño | $18,000 a $24,000 MXN |
| Municipal profesional | Municipio mediano | $36,000 a $48,000 MXN |

## Alcance del MVP vendible

Incluye:

- usuarios y roles,
- organigrama,
- registro de oficios,
- carga de PDF,
- turnado,
- seguimiento,
- cierre,
- dashboard,
- reportes,
- alertas internas,
- panel SaaS.

No incluye todavía:

- firma avanzada con e.firma,
- pagos automáticos,
- app móvil nativa,
- integración con sistemas externos.

## Modelo de implementación

1. Alta del municipio.
2. Carga inicial de áreas.
3. Creación de usuarios.
4. Capacitación breve.
5. Operación piloto.
6. Ajustes comerciales.
7. Activación anual.
